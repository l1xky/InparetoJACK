INPARETO — Termux 0.119+ quick guide
Developed by S Crew

INSTALL (one command)
────────────────────
curl -fsSL https://raw.githubusercontent.com/l1xky/InparetoJACK/main/setup.sh -o setup.sh
bash setup.sh

Do NOT use old setup-termux.sh or a random file named "s".

RUN (two Termux windows)
────────────────────────
Window 1 (API first — Posts count needs this):
  cd ~/inpareto
  bash start-api.sh

Window 2:
  cd ~/inpareto
  bash start-bot.sh

Posts show N/A?
  • Keep endpoint.py running in window 1
  • git pull — update BOTH joint.py + endpoint.py, restart both
  • Do NOT pip install tls_client on Termux (crashes — libpthread.so.0)
  • IG may rate-limit mobile data — try Wi‑Fi or VPN

TELEGRAM
────────

2. Join required channels, tap Verify
3. Create hit group, add bot as ADMIN
